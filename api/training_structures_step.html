training_structures_step.export module#

The labelled training points of one molecule: relative energies, the filters, the extended-XYZ file and the coverage counts, as plain functions (no flowchart state) so that they can be tested on their own.

Energies are in kJ/mol and gradients in kJ/mol/Å, as the Energy step stores them, unless a name says otherwise.

Relative energies and the filters, for one molecule’s labelled points.

Parameters:

  • points ([dict]) – One per configuration, in order, each with “name”, “type” (the Training Structures point type), “energy” (kJ/mol or None when unlabelled), “gradients”, “fingerprint” (the settings fingerprint or None) and “S**2” (or None). Exactly one has type “minimum”.

training_structures_step.export.merge_redraw(points, redraw_points, same_model=True, tolerance=0.01)[source]#

A molecule’s points with a redraw’s samples in place of the first pass’s.

The first pass’s samples are kept in the list, marked “replaced” (so the caller can mark their configurations); the redraw’s minimum is a duplicate of the first pass’s and is left out. Both minima must agree in energy (within tolerance kJ/mol) and settings: the redraw must start from the same structure at the same level.

Return type:

(points, problem)

The heavy rotors of a molecule, most heavy atoms moved first.

A heavy rotor is an acyclic single bond i-j, not conjugated, where i and j each have another heavy-atom neighbour (so methyl, OH and NH2 rotations are not rotors). class training_structures_step.substep.Substep(flowchart=None, title='no title', extension=None, logger=<Logger training_structures_step.substep (WARNING)>, module=None)[source]#

Bases: Node

A base class for substeps in the Training Structures subflowchart.

The top-level TrainingStructures step iterates over the substeps of its subflowchart and calls each substep’s run() method. Each substep is responsible for preparing its own input, invoking Training Structures, analyzing its output, and storing its results.

This base class provides:

  • is_runable - whether the top-level loop should call run() on this substep. Override to return False for substeps that only contribute input (e.g., an Initialization step) rather than invoking the code.

  • input_only - a flag for “write input but don’t run” mode, useful for debugging and testing.

  • options / global_options - delegated to the parent step so that command-line options reach substeps uniformly.

  • header - a printable header for this section of step.out.

  • version / git_revision - delegated to the plug-in package so that every substep reports the plug-in’s version, not seamm.Node’s.

Bases: Parameters

The control parameters for Training Structures.

The step makes distorted structures of one molecule (the current configuration, which should be a minimum of the flowchart’s Model Chemistry) for training a machine-learned potential: normal-mode samples at targeted energies, relaxed torsion scans of the heavy rotors, and bond stretches. The Hessian comes from the Model Chemistry; the scans and the pre-screen use a second, cheap level.

Helper class needed for the stevedore integration.

This must provide a description() method that returns a dict containing a description of this node, and create_node() and create_tk_node() methods for creating the graphical and non-graphical nodes.

The dictionary for the description is the class variable just below these comments. The felds are as follows:

my_description{str, str}

A human-readable description of this step. It can be several lines long, and needs to be clear to non-expert users. It contains the following keys: description, group, name.

my_description[“description”]tuple

A description of the Training Structures step. It must be clear to non-experts.

my_description[“group”]str

Which group in the menus to put this step. If the group does not exist it will be created. Common groups are “Building”, “Control”, “Custom”, “Data”, and “Simulations”.

my_description[“name”]str

The name of this step, to be displayed in the menus.
